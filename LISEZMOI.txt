LE CARTABLE MAGIQUE – application installable (PWA)
M. Guitton – fichiers mis au point avec l'aide de Claude AI.

ADRESSE : https://mickaelguitton.github.io/cartable-magique/

CONTENU DU DÉPÔT
  index.html               la page d'accueil (les tuiles)
  calcul-mental/           un dossier par outil, contenant son index.html
  gym-des-mots/
  machine-conjugaison/
  a-qui-le-tour/
  images/                  les captures affichées sur les tuiles
  version.js               LE numéro de version (seul fichier à modifier pour déclencher une mise à jour : 1.0 → 1.1…)
  portail.js               bouton « Accueil », version et mise à jour dans chaque outil (ne pas modifier)
  sw.js                    fonctionnement hors ligne + mises à jour (à compléter seulement pour ajouter un outil)
  manifest.webmanifest     nom, icônes et affichage plein écran de l'application
  fonts/, icon-*.png, apple-touch-icon.png, favicon.png
  LICENSE                  la licence CC BY-NC 4.0
  .nojekyll                fichier vide utile à GitHub Pages

PUBLIER UNE NOUVELLE VERSION D'UN OUTIL
  1. Remplacer le fichier index.html dans le dossier de l'outil.
  2. Changer le numéro dans version.js (1.0 → 1.1).
  Au prochain lancement avec internet, l'application se met à jour toute seule.

AJOUTER UN OUTIL
  1. Créer son dossier avec son index.html (et les lignes du portail : voir les autres outils).
  2. Ajouter sa capture dans images/ et sa tuile dans index.html (copier une tuile existante).
  3. Ajouter son dossier et sa capture dans la liste FILES de sw.js.
  4. Changer le numéro dans version.js.

STATISTIQUES ANONYMES
  L'appli envoie des statistiques anonymes (sans cookie ni donnée personnelle) à GoatCounter :
  installations, nombre d'ordinateurs différents (« Nouvel ordinateur ») et ouvertures du portail
  et de chaque outil. Tableau de bord : https://cartable-magique.goatcounter.com
  Rien n'est affiché dans l'appli. Le code se trouve dans portail.js (partie 4).
